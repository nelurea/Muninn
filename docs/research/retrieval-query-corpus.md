# Retrieval Queries (Raw Dataset)

Status: Internal Research Material
Visibility: Private

This document contains the original retrieval-query dataset collected during Issue #7.

The dataset consists of more than 100 natural-language examples describing how people attempt to retrieve previously saved images.

Examples may include:

- creator-based retrieval
- memory-fragment retrieval
- emotional retrieval
- temporal retrieval
- session retrieval
- purpose-based retrieval
- relationship-based retrieval
- source-based retrieval

The raw dataset intentionally remains separate from public research artifacts because many examples contain highly personal, niche, or context-specific language.

The purpose of this dataset is not publication.

The purpose is pattern extraction.

Outputs derived from this dataset are documented in:

- retrieval-patterns.md
- context-model-v0.1.md
